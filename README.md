# MAS Safer — experimental r3

Локальная экспериментальная производная Microsoft Activation Scripts 3.14.
Цель проекта — более предсказуемая обработка ошибок, сохранение исходных файлов,
просмотр предполагаемых изменений и журнал восстановления.

**Независимая проверка активации Windows/Office не проводилась.** Ревизии 2 и 3
проверялись только статически. Их тесты, компиляция, активация, новый режим плана
и код журналирования не запускались. Старые результаты тестов относятся только
к первой ревизии. GitHub Actions отключены; автоматического запуска скриптов нет.

13 ноября 2026 владелец проекта сообщил, что проверил работу сначала
на виртуальной машине, затем на физическом ПК и не заметил проблем.
Это результат пользовательской проверки. Точные версии Windows/Office,
способ активации и идентификатор проверенной сборки не указаны;
логи и независимое воспроизведение не предоставлены.

## Что добавлено

Явное сохранение хранилищ и подготовка файлов до замены; резервные копии
и попытка файлового отката; проверки структуры и контрольных сумм;
более осторожные настройки автоматических изменений; исправления
обработки ошибок Ohook/TSforge и диагностических сообщений.

В ревизии 3 появились `View-Plan.cmd` и `/Plan`, а также журналы основных
этапов и подробных файловых операций. Просмотр плана не продолжает выполнение
в активацию. Журнал не восстанавливает полностью ключи, реестр, службы,
планировщик или удалённое состояние активации.

Новые возможности требуют Windows PowerShell 5.1. Совместимость текущего
варианта с реальной Windows не проверена. Этот репозиторий не является
официальным релизом massgravel или продуктом Microsoft.
