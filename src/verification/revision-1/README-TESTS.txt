Тесты локальной safer-сборки

Это испытания на искусственных файлах. Они не активируют систему, не вызывают
Windows licensing APIs и не подтверждают активацию Windows/Office.

PatchedFull.cs — точный C#, извлечённый из распространяемого MAS_AIO.cmd.
verify_source.py также сверяет его с отдельной версией TSforge.
fixtures/*.dat созданы исходным TokenStoreModern на искусственных записях;
в них нет пользовательских лицензий, ключей или данных компьютера.

Для повторения C#-проверок нужны Python 3 и совместимый .NET SDK/runtime
для проекта net7.0. В использованной среде был SDK 7.0.102, runtime 7.0.2.

  python verification/run_storage_tests.py

Скрипт создаёт verification/test-run, копирует туда тестовые fixtures,
компилирует полный C# с LangVersion=3 и выполняет Program.Main.
Сначала используется точный производственный C# (33 проверки), затем
тестовая копия TestFull.cs с ОДНОЙ инъекцией IOException непосредственно
перед второй заменой файла (34 проверки, из которых 33 повторные).
TestFull.cs не попадает внутрь распространяемых CMD. Ошибка вставляется
генератором теста, а не переключателем среды в производственном коде.

Проверяются:
  - исключение внутри using без неявного сохранения;
  - отсутствие изменений при чтении и сохранение только по Commit;
  - точная резервная копия;
  - отсутствие роста/потери записей при повторной сериализации;
  - повреждённые размеры, хеши, версия, указатели, циклы;
  - отсутствие создания пропавшего хранилища;
  - незавершённая и успешная группа записи;
  - откат первой замены при отказе второй;
  - пять форматов physical store и обе зеркальные копии у Vista/Win7.

Check-PowerShell.ps1 разбирает 45 встроенных PowerShell-блоков, проверяет
декодирование/хеши DLL и отказ при повреждении/неизвестном файле. Он загружает
ТОЛЬКО определения функций помощника Ohook до switch, не запускает установку,
не обращается к реестру, службам или Task Scheduler. Для неизвестного DLL
проверяется именно сообщение о неизвестной DLL, а не произвольное исключение.
Проверка проводилась парсером PowerShell 7.7.0 на macOS.

Test-Windows-Compile.ps1 — отдельная НЕ ВЫПОЛНЕННАЯ здесь проверка компиляции
под Windows PowerShell 5.1/.NET Framework. Она не запускает активацию.

Полезный следующий этап именно для совместимости — тестовая Windows VM:
проверка компиляции, выбранный способ активации, штатная проверка результата,
перезапуск, повторный запуск и восстановление снимка. Отдельно испытываются
Ohook uninstall, ACL/подписи и задачи KMS. Результаты этих этапов не заявлены.
